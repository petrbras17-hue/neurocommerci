## 2. Бизнес-профиль: кто покупает в Азии

### Сегмент 1: E-commerce / D2C бренды (40% потенциала)

**Индия** — D2C рынок $108,76 млрд (2026), растет с CAGR 24,3%:
- Shopify-бренды (D2C): 5,000+ активных магазинов в Индии
- Meesho-продавцы: 120 млн MAU, $5 млрд+ GMV, social commerce модель
- Заказы из малых городов > 50% GMV на Meesho
- Потребность: комментарии для продвижения товаров, парсинг конкурентов, автоматизация каналов

**Индонезия / Филиппины**:
- Tokopedia, Shopee, Lazada продавцы используют Telegram для оповещений
- Social commerce через группы — нативная модель продаж

**Ценовой порог**: $10-30/мес для мелких D2C, $50-100/мес для средних

### Сегмент 2: Crypto / Web3 проекты (30% потенциала)

- Индия #1 в мире по крипто-адопции (Chainalysis Global Adoption Index 2025)
- Индонезия #6, Филиппины #7-9 глобально
- 2,2k+ крипто-каналов только в Индии (TGStat)
- Каждый Web3 проект ведет Telegram-канал + группу
- Крипто-агентства (TokenMinds SG, FINPR, Coinbound) — потенциальные партнеры/клиенты

**Потребность**: community growth, engagement farming, sentiment monitoring, shill automation
**Ценовой порог**: $50-200/мес (крипто-проекты платят больше)

### Сегмент 3: EdTech (15% потенциала)

- 6,3k+ образовательных каналов в Индии
- Крупнейшие: Maths By Gagan Pratap (2,17 млн), Utkarsh Classes (1,03 млн), Rankers' Gurukul (940k)
- Подготовка к госэкзаменам (SSC, UPSC, Banking) — массовый рынок
- Индонезия: Ruangguru, Zenius — EdTech гиганты с Telegram-каналами

**Потребность**: рост подписчиков, вовлечение, авто-ответы, парсинг конкурентов
**Ценовой порог**: $15-50/мес

### Сегмент 4: Gaming / Mini Apps (10% потенциала)

- Hamster Kombat: 43+ млн подписчиков, огромная база в Азии
- Notcoin + Hamster вместе: 300+ млн игроков на пике
- TON Mini Apps ecosystem: 950 млн MAU через Telegram
- Разработчики мини-приложений нуждаются в продвижении

**Потребность**: массовые реакции, комментинг, пользовательский парсинг
**Ценовой порог**: $20-100/мес

### Сегмент 5: Influencers / KOLs (5% потенциала)

- 70% админов каналов зарабатывают через рекламу/спонсорства
- Микро/нано-инфлюенсеры — растущий тренд в 2025-2026
- Потребность в аналитике, автоматизации постинга, cross-promotion

**Ценовой порог**: $5-25/мес

### Стратегия локализации

1. **UI**: English + Hindi сразу, остальные — через i18n framework (react-intl / next-intl)
2. **AI-комментарии**: мультиязычные через AI router (модели уже поддерживают все эти языки)
3. **Поддержка**: English-first, Hindi bot для Индии, local partners для ЮВА
4. **Контент**: landing pages на местных языках, SEO на Hindi/Bahasa
5. **Юридические страницы**: /terms, /privacy на English + местном языке для каждого рынка

### Особенности скриптов

- Hindi: Devanagari script, RTL не нужен (LTR), но нужен Unicode support
- Thai: без пробелов между словами — специальная обработка для word wrapping
- Bengali: сложные лигатуры — убедиться что шрифты поддерживают
- Vietnamese: диакритические знаки — проверить input validation и search

## 10. Риски и митигация

| Риск | Вероятность | Импакт | Митигация |
|------|-------------|--------|-----------|
| Telegram ban в Индии (как в 2020 в Таиланде) | Низкая (5%) | Критический | Диверсификация: WhatsApp/Discord бот |
| Ценовая война с SMM-панелями (₹10/1000) | Высокая (70%) | Средний | Позиционирование: AI + anti-detection vs fake engagement |
| Медленная адопция из-за PPP-цен ниже unit economics | Средняя (40%) | Высокий | Usage-based pricing, freemium tier, crypto upsell |
| Регуляторные риски крипто (Индия: 30% налог) | Средняя (50%) | Средний | Диверсификация сегментов, не только крипто |
| Локализация дороже, чем ожидалось | Средняя (40%) | Низкий | AI-перевод (GPT/Claude), community translations |
| Платежные провайдеры отказывают (Telegram automation = gray area) | Средняя (30%) | Высокий | TON/крипто как primary, Razorpay как backup |
