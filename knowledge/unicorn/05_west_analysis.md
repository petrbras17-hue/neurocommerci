## 5. GDPR / Privacy: Compliance для EU

### 5.1 Текущий статус Telegram и GDPR

| Аспект | Статус |
|--------|--------|
| DPA (Data Processing Agreement) | Telegram НЕ предоставляет DPA |
| Шифрование | E2E только в Secret Chats, обычные чаты -- серверное |
| Юрисдикция | Dubai (UAE) -- нет EU adequacy decision |
| Cross-border transfers | Серверы вне EU -- проблема под GDPR |
| EU DSA compliance | Telegram выполняет EU Digital Services Act (отдельная страница ToS) |
| Модерация | 34+ млн групп/каналов заблокировано в 2025 |

### 5.2 Что это значит для NEURO COMMENTING

**Правовые риски автоматизации в EU:**

1. **Automated messaging** -- требует explicit consent (opt-in). Нельзя делать mass outreach без разрешения.
2. **Data collection** -- парсинг публичных каналов = допустимо (legitimate interest), но хранение PII (имена, телефоны) требует правовой базы.
3. **Profiling** -- AI-генерация профилей пользователей может попадать под automated decision-making (Article 22 GDPR).
4. **Right to erasure** -- если мы храним данные о пользователях каналов, они имеют право на удаление.

### 5.3 Обязательные compliance-меры для EU launch

| Мера | Приоритет | Сложность |
|------|-----------|-----------|
| Privacy Policy (EN, DE, FR, IT, ES) | P0 | Средняя |
| Cookie consent / tracking consent | P0 | Низкая |
| DPA template для клиентов | P0 | Средняя |
| Data retention policy (auto-purge) | P1 | Средняя |
| Right to erasure API endpoint | P1 | Средняя |
| Data export (portability) endpoint | P1 | Низкая |
| EU data residency option (EU servers) | P2 | Высокая |
| DPIA (Data Protection Impact Assessment) | P2 | Высокая |
| "GDPR mode" toggle (no PII storage) | P1 | Средняя |
| ePrivacy compliance (consent for tracking) | P1 | Средняя |

### 5.4 Юридическая структура для EU

Рекомендуемая структура:
- **EU entity** (например, в Эстонии -- e-Residency, быстрая регистрация, EU jurisdiction)
- **DPA** как data processor для клиентов
- **Standard Contractual Clauses (SCC)** для трансферов данных вне EU
- **Appointed EU Representative** (Article 27 GDPR) если нет EU entity

### 10.2 Ключевые действия для Western launch

1. **English UI** -- обязательно для P0 рынков. Перевод всего frontend + onboarding + docs.
2. **GDPR compliance mode** -- обязательно для EU. Privacy policy, DPA, data retention, erasure API.
3. **Product Hunt launch** -- бесплатный канал с высоким quality трафиком.
4. **Crypto/Web3 partnerships** -- самый горячий сегмент с высоким ARPU.
5. **Pricing localization** -- $99-999/мес для West vs $15-130/мес для RU/CIS.
6. **Content marketing** -- LinkedIn, Medium, Twitter/X. Thought leadership в Telegram growth.
