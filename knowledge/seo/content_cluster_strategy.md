### URL-структура
```
neurocommenting.com/blog/                         <- Index
neurocommenting.com/blog/{pillar-slug}/           <- Pillar Pages
neurocommenting.com/blog/{pillar-slug}/{post}/    <- Cluster Posts
neurocommenting.com/blog/compare/{post}/          <- Comparisons
neurocommenting.com/blog/guides/{post}/           <- How-to Guides
```

### Обязательные SEO-элементы на каждой странице блога

1. **Title tag**: `{H1} | NEURO COMMENTING` (50-60 символов)
2. **Meta description**: уникальная, 150-160 символов, с CTA
3. **Canonical URL**: `<link rel="canonical" href="...">`
4. **Hreflang**: для каждого языка
5. **OG tags**: title, description, image (1200x630 PNG), url
6. **Twitter Card**: summary_large_image
7. **JSON-LD**: Article, BreadcrumbList, Organization
8. **H1**: один на страницу, содержит target keyword
9. **Alt tags**: на всех изображениях
10. **Internal links**: минимум 3 на пост
11. **External links**: 1-2 авторитетных источника
12. **Table of Contents**: для постов 1500+ слов
13. **Related Posts**: блок из 3 постов внизу
14. **Author box**: имя, фото, bio (E-E-A-T)
15. **Published date + Updated date**: в schema и visually
