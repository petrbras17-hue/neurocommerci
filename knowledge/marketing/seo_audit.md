## 2. TECHNICAL SEO (25/100)

### 2.1 Домен

**КРИТИЧЕСКАЯ ПРОБЛЕМА:** Сайт работает на `neurocommenting.com` -- wildcard DNS-сервис.
- Поисковые системы ранее не индексировали sslip.io-поддомены (теперь на neurocommenting.com)
- Нет собственного домена = невозможно строить авторитет
- Backlinks бесполезны на временном домене
- Google может расценить как подозрительный сайт

**Рекомендация:** Купить домен немедленно. Варианты:
- `neurocommenting.ru` (основной)
- `neurocommenting.com` (международный)
- `nc-growth.ru` (короткий)
- `telegramgrowth.ru` (ключевой)

### 2.2 robots.txt

```
User-agent: *
Allow: /
Sitemap: /sitemap.xml
```

**Проблемы:**
- Не блокирует `/app/*` (SPA-приложение, не нужно индексировать)
- Не блокирует `/auth/*` (служебные endpoints)
- Не блокирует `/v1/*` (API endpoints)
- Не блокирует `/health` (служебный endpoint)
- Sitemap URL содержит IP-адрес вместо домена

**Рекомендуемый robots.txt:**
```
User-agent: *
Allow: /
Allow: /ecom
Allow: /edtech
Allow: /saas
Allow: /pricing
Allow: /terms
Allow: /privacy
Allow: /refund
Disallow: /app
Disallow: /auth
Disallow: /v1
Disallow: /health
Disallow: /api
Sitemap: https://neurocommenting.ru/sitemap.xml
```

### 2.3 Sitemap.xml

**Текущий sitemap генерируется динамически из `MARKETING_PAGES`:**
- Содержит только 4 страницы: `/`, `/ecom`, `/edtech`, `/saas`
- **НЕ содержит:** `/pricing`, `/terms`, `/privacy`, `/refund`
- Нет `<lastmod>`, `<changefreq>`, `<priority>` -- Google снижает доверие
- Content-Type: `application/xml` -- OK

**Рекомендация:** Добавить все публичные страницы + метаданные:
```xml
<url>
  <loc>https://neurocommenting.ru/</loc>
  <lastmod>2026-03-16</lastmod>
  <changefreq>weekly</changefreq>
  <priority>1.0</priority>
</url>
<url>
  <loc>https://neurocommenting.ru/pricing</loc>
  <lastmod>2026-03-16</lastmod>
  <changefreq>monthly</changefreq>
  <priority>0.8</priority>
</url>
```

### 2.4 Canonical URLs

**КРИТИЧЕСКАЯ ПРОБЛЕМА: отсутствуют `<link rel="canonical">`** на всех страницах.
- Без canonical поисковик может индексировать дубликаты (http/https, www/без www, с параметрами)
- OG:URL заполнен (`{{ base_url }}{{ request.url.path }}`), но canonical отсутствует

### 2.5 Hreflang

- Отсутствуют `<link rel="alternate" hreflang="ru">` теги
- Сайт только на русском, но даже для mono-language рекомендуется указать `hreflang="ru"`
- Если планируется EN-версия, нужно добавить hreflang заранее

### 2.6 SSL / HTTPS

- HTTPS через Let's Encrypt / Cloudflare на neurocommenting.com
- HTTPS-redirect настроен в middleware (`_request_is_secure`)
- На собственном домене нужен будет Let's Encrypt / Cloudflare

### 2.7 Favicon

- Используется SVG (`og-default.svg`) -- не все браузеры полностью поддерживают SVG favicon
- Нет `<link rel="icon">` в HTML -- браузер запрашивает `/favicon.ico` (перенаправлен)
- Нет `apple-touch-icon`, `manifest.json`

### 2.8 Скорость загрузки

**Хорошо:**
- Один CSS-файл (marketing.css, 1088 строк, ~25KB)
- Inline JS минимальный (hamburger + form submit)
- Preconnect для Google Fonts
- Нет тяжелых JS-фреймворков на маркетинговых страницах

**Проблемы:**
- CSS не минифицирован
- Google Fonts грузятся external (render-blocking) -- Inter (5 weights) + JetBrains Mono (4 weights) = ~200KB
- Нет `<link rel="preload">` для критических ресурсов
- Нет `font-display: swap` в локальном CSS (хотя Google Fonts `display=swap` передан)
- Нет gzip/brotli сжатия (зависит от nginx-конфига)
- Нет lazy-loading (нет изображений, не применимо)

### 2.9 Structured Data / Schema.org

**КРИТИЧЕСКАЯ ПРОБЛЕМА: полностью отсутствует JSON-LD разметка.**

Необходимые типы schema:
- `Organization` -- на всех страницах
- `WebSite` + `SearchAction` -- на главной
- `Product` или `SoftwareApplication` -- на главной/landing
- `FAQPage` -- на главной и /pricing (FAQ есть, но без schema)
- `Offer` / `PriceSpecification` -- на /pricing
- `BreadcrumbList` -- на всех страницах

### 2.10 Open Graph / Twitter Cards

**OG-теги присутствуют на всех страницах (хорошо):**
- `og:title`, `og:description`, `og:type`, `og:image`, `og:url`

**Проблемы:**
- Нет `og:locale` (`ru_RU`)
- Нет `og:site_name` (`NEURO COMMENTING`)
- OG-image -- SVG (Telegram/Twitter/Facebook не поддерживают SVG для preview)
- Нет Twitter Card мета-тегов (`twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`)
