## 1. Реферальная программа

### 1.1 Механика: Give $20 / Get $20

| Действие | Реферал получает | Приглашённый получает |
|----------|-----------------|----------------------|
| Регистрация по реферальной ссылке | — | 7 дней бесплатного Pro (вместо стандартных 14 дней триала Basic) |
| Приглашённый оплачивает первый месяц | $20 кредит на счёт | $20 скидка на первый платёж |
| Приглашённый остаётся 3+ месяца | +$10 бонус | — |

Формат ссылки: `https://neurocommenting.io/r/{ref_code}`
Альтернатива: промокод `NC-{USERNAME}` для ввода при регистрации.

### 1.2 Уровни реферальной программы

| Уровень | Требование | Комиссия с оплат рефералов | Бонусы |
|---------|------------|---------------------------|--------|
| **Bronze** | 1-4 приглашённых | 10% recurring (12 мес) | Бейдж в профиле |
| **Silver** | 5-14 приглашённых | 15% recurring (12 мес) | + приоритетная поддержка |
| **Gold** | 15-49 приглашённых | 20% recurring (18 мес) | + ранний доступ к фичам, закрытый чат |
| **Platinum** | 50+ приглашённых | 25% recurring (24 мес) | + персональный менеджер, co-branding |

Recurring комиссия начисляется от каждого платежа приглашённого пользователя в течение указанного срока.

### 1.3 Награды для рефералов

- **Кредиты**: начисляются на баланс, списываются при следующем платеже
- **Вывод**: от $100 — вывод на карту/USDT (только Silver+)
- **Апгрейд**: 10 рефералов = бесплатный месяц текущего плана
- **Мерч**: 25 рефералов = брендированный мерч-пак
- **Lifetime**: 100 рефералов = пожизненный Pro-план

### 1.4 Награды для приглашённых

- 7 дней Pro вместо 14 дней Basic триала (апгрейд триала)
- $20 скидка на первый платёж
- Бонусные 500 AI-генераций комментариев
- Доступ к 3 premium шаблонам комментирования

### 1.5 Anti-Fraud правила

| Правило | Описание |
|---------|----------|
| **Email verification** | Приглашённый должен подтвердить email перед активацией реферала |
| **Unique IP** | Реферал и приглашённый не могут иметь один IP при регистрации |
| **Payment verification** | Комиссия начисляется только после успешного платежа (не триала) |
| **Self-referral block** | Один tenant не может пригласить свой же дополнительный аккаунт |
| **Abuse detection** | >5 регистраций с одного IP за 24ч = заморозка реферальных начислений |
| **Chargeback clawback** | Если приглашённый делает chargeback — комиссия списывается обратно |
| **Minimum activity** | Приглашённый должен совершить хотя бы 1 действие в продукте (создать ферму / запустить парсинг) |
| **Cooldown** | Между реферальными регистрациями с одного реферала — минимум 1 час |
| **KYC для вывода** | Вывод от $100 требует верификацию (Telegram ID + документ) |

## 2. Growth Loops

### 2.1 Viral Loop — продукт распространяется сам

```
Пользователь запускает ферму комментирования
  → Комментарии появляются в публичных каналах
    → Владельцы каналов видят умные комментарии
      → Интересуются инструментом (watermark в профиле бота: "Powered by NEURO COMMENTING")
        → Переходят на лендинг → Регистрация
          → Запускают свою ферму → Цикл повторяется
```

**Усилители viral loop:**

1. **Watermark-профили**: аккаунты фермы содержат в bio ссылку на платформу (опционально, +5% к AI-лимиту за включение)
2. **Smart Comment Signature**: в 1 из 20 комментариев — микро-ватермарк: "// сгенерировано ИИ — neurocommenting.io" (отключается на Pro+)
3. **Channel Map публичный доступ**: `/app/channel-map` доступна без авторизации в read-only режиме — SEO-магнит
4. **Share-кнопка на аналитике**: "Поделиться результатами кампании" генерирует красивую карточку с метриками → шеринг в Telegram/Twitter
5. **Invite-to-workspace**: пригласить коллегу в воркспейс = реферальная ссылка с контекстом

### 2.2 Content Loop — контент генерирует лидов

```
Платформа собирает анонимизированные метрики
  → Автогенерация еженедельного отчёта "Telegram Growth Digest"
    → Публикация в Telegram-канале + рассылка
      → Подписчики видят инсайты с реальными данными
        → Переходят на платформу → Регистрация
          → Их данные обогащают следующий отчёт → Цикл повторяется
```

**Контент-машина:**

| Формат | Частота | Канал | Цель |
|--------|---------|-------|------|
| Telegram Growth Digest | Еженедельно | Telegram-канал, email | Привлечение + удержание |
| Кейс-стади клиентов | 2 в месяц | Блог, Telegram | Social proof |
| "Канал недели" из Channel Map | Еженедельно | Telegram, Twitter | Вовлечение владельцев каналов |
| Видео-туториалы | 2 в месяц | YouTube, Telegram | SEO + обучение |
| Шаблоны комментариев | Еженедельно | Telegram, блог | Lead magnet |
| ROI-калькулятор | Постоянно | Лендинг | Конверсия |

**Content Factory интеграция**: модуль `core/content_factory.py` уже умеет трансформировать 1 источник в 6 форматов — использовать для автоматизации контент-машины.

### 2.3 Community Loop — Telegram-комьюнити

```
Пользователь регистрируется
  → Приглашение в закрытый Telegram-чат "NEURO COMMENTING Community"
    → Видит кейсы и вопросы других пользователей
      → Задаёт вопрос → получает помощь → чувствует ценность
        → Рекомендует коллегам → Те регистрируются
          → Присоединяются к чату → Цикл повторяется
```

**Структура комьюнити:**

| Чат/Канал | Доступ | Цель |
|-----------|--------|------|
| @neurocommenting_news | Публичный | Новости, обновления, кейсы |
| @neurocommenting_chat | По регистрации | Поддержка, обсуждения |
| @neurocommenting_gold | Gold+ рефералы | Закрытый клуб, бета-фичи |
| @neurocommenting_agency | Agency partners | Партнёрский чат |

**Community mechanics:**
- Бот в чате автоматически приветствует новых участников
- Еженедельный "Q&A час" с командой
- Топ-3 помощника месяца получают бонусные кредиты
- Эксклюзивные промокоды только для участников чата

## 3. Partnership Program

### 3.1 Типы партнёров

| Тип | Описание | Целевой профиль |
|-----|----------|----------------|
| **Agency Partner** | Агентства, использующие платформу для клиентов | SMM-агентства, digital-агентства, 5-50 клиентов |
| **Integrator** | Техн. партнёры, интегрирующие API | CRM-разработчики, Telegram-боты, SaaS-платформы |
| **Influencer** | Лидеры мнений в маркетинг-нише | Telegram-каналы 5K+ подписчиков, YouTube 1K+ |
| **Reseller** | Перепродажа под своим брендом | Фрилансеры, мелкие агентства в регионах |

### 3.2 Revenue Share модель

| Тип партнёра | Revenue Share | Срок | Минимум для участия |
|-------------|--------------|------|---------------------|
| Agency Partner | 20% от платежей клиентов | 24 мес | 3 активных клиента |
| Integrator | 15% от привлечённых через интеграцию | 18 мес | Работающая интеграция |
| Influencer | 25% от первых 6 мес каждого клиента | 6 мес | 1 публикация/обзор |
| Reseller (White Label) | 30-40% маржа (партнёр ставит свою цену) | Бессрочно | Agency Package подписка |

### 3.3 Agency Partner — детали

- Доступ к Agency Dashboard (`/app/agency`)
- White Label: своё лого, цвета, домен (уже реализовано в Sprint 15)

### 3.4 Onboarding партнёров

```
1. Заявка на /partners (лендинг)
2. Квалификация (5 мин звонок или Telegram-чат)
3. Подписание партнёрского соглашения (электронно)
4. Создание партнёрского аккаунта + дашборд
5. Обучающий звонок (30 мин) + доступ к Partner Academy
6. Первый клиент → активация revenue share
7. Квартальный review с account manager
```

**Partner Academy** (self-serve):
- 5 видео-модулей по платформе
- Шаблоны pitch-презентаций для клиентов
- ROI-калькулятор для агентств
- Готовые кейс-стади для перепродажи
- Брендированные материалы (лого, скриншоты, описания)

## 5. Retention Mechanics

### 5.1 Habit Loops

**Daily Hook — "Утренний дайджест":**
```
Триггер: 09:00 по часовому поясу пользователя
  → Push в Telegram-бот: "Ваша ферма за ночь: 47 комментариев, 0 банов, quality 94%"
    → Клик → открывает /app/dashboard
      → Видит метрики → Чувствует прогресс
        → Запускает/настраивает ферму на день
          → Завтра → Триггер повторяется
```

**Weekly Hook — "Недельный отчёт":**
```
Триггер: Понедельник 10:00
  → Email + Telegram: "Итоги недели: 312 комментов, охват 45K, ROI +12%"
    → Сравнение с прошлой неделей (рост/падение)
      → Рекомендации: "Добавьте 2 аккаунта для x2 результата"
        → Мотивация к апгрейду плана
```

**Action Loop — "Прогресс-бар до следующего уровня":**
- В sidebar всегда виден прогресс до следующего achievement
- "Ещё 23 комментария до достижения Мастер слова"
- Психологический эффект "незавершённого действия" (Зейгарник)

### 5.2 Engagement Hooks

| Hook | Механика | Цель |
|------|----------|------|
| **Streak counter** | "7 дней подряд активная ферма" — бонус за непрерывность | Ежедневный вход |
| **Quality alerts** | "Quality Score упал до 82% — рекомендуем сменить стиль" | Возврат в продукт |
| **Channel suggestions** | "Найдено 15 новых каналов в вашей нише" (из Channel Map) | Регулярный парсинг |
| **A/B results** | "Стиль 'Провокатор' дал +40% engagement — переключить?" | Эксперименты |
| **Account health** | "Аккаунт @name: здоровье 65%, рекомендуем паузу на 2 дня" | Забота о ресурсах |
| **Competitor alert** | "В канале X появился новый активный комментатор" | Конкурентная мотивация |
| **Milestone proximity** | "До 1000 комментариев осталось 47 — не останавливайтесь!" | Gamification |

### 5.3 Switching Costs (барьеры для ухода)

| Барьер | Описание | Сила |
|--------|----------|------|
| **Данные и история** | История комментариев, аналитика, A/B тесты — не экспортируются к конкуренту | Высокая |
| **Обученные стили** | Кастомные стили комментирования, обученные на данных клиента | Высокая |
| **Прогретые аккаунты** | Аккаунты с историей warmup — начинать заново у конкурента = 2-4 недели | Очень высокая |
| **Channel Map база** | Распарсенные и размеченные каналы с blacklist/whitelist | Средняя |
| **Интеграции** | Google Sheets, Telegram-бот, webhooks — перенастройка стоит времени | Средняя |
| **Реферальный доход** | Recurring комиссия теряется при уходе | Высокая |
| **Agency клиенты** | White label клиенты привязаны к платформе, миграция болезненна | Очень высокая |
| **Достижения и статус** | Потеря Gold/Platinum статуса и накопленных бейджей | Низкая-средняя |
| **Скидки за стаж** | -10% / -20% навсегда — у конкурента придётся платить полную цену | Средняя |

### 5.4 Churn Prevention Triggers

| Сигнал | Действие |
|--------|----------|
| 3 дня без входа | Push: "Ваша ферма на паузе — запустить?" |
| 7 дней без входа | Email: "Что случилось? Вот что вы пропустили" + метрики за неделю |
| Downgrade запрос | Предложить: "Заморозка на 1 месяц вместо отмены" (сохранить данные) |
| Cancel flow | 3 шага: причина → предложение (скидка -30% / пауза / помощь) → подтверждение |
| Оплата не прошла | 3 попытки с интервалом 3 дня + Telegram-уведомление + grace period 7 дней |
| Quality Score < 70% | Проактивная помощь: "Давайте настроим ферму вместе — бесплатная сессия 15 мин" |
