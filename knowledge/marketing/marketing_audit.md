## 1. Brand Readiness -- 3/10

### Что есть:
- Название "NEURO COMMENTING" закреплено
- Текстовый логотип "NC" (CSS-generated brand-mark)
- Единый цветовой стиль: dark terminal (#0a0a0b фон, #00ff88 акцент)
- Шрифты: Inter + JetBrains Mono
- OG-image: `og-default.svg` (SVG-заглушка)

### Критические проблемы:
- **Нет настоящего логотипа** -- "NC" в CSS-квадрате не является логотипом для бренда
- **Нет favicon** -- используется SVG-заглушка вместо настоящего .ico/.png
- **Нет брендбука** -- цвета, шрифты, использование нигде не документированы
- **OG-image** -- SVG-заглушка, при шаринге в Telegram/соцсетях будет выглядеть непрофессионально
- **Нет альтернативных форматов логотипа** -- нужны PNG, SVG, light/dark варианты

### Рекомендации:
1. Заказать профессиональный логотип (Figma/дизайнер)
2. Создать OG-image 1200x630px в PNG для Telegram/соцсетей
3. Сгенерировать favicon в форматах .ico + .png (16x16, 32x32, 180x180)
4. Подготовить мини-брендбук (цвета, шрифты, лого на светлом/темном)

## 2. Website Readiness -- 6/10

### Что есть:
- Лендинг с hero-секцией, features, pricing-блоком, FAQ, lead-формой
- 3 вертикальных страницы: /ecom, /edtech, /saas
- Отдельная страница тарифов /pricing с 6 планами
- Мобильная навигация (hamburger-меню)
- robots.txt и sitemap.xml
- Jinja2-шаблоны с динамическим контентом
- UTM-трекинг в lead-форме
- PWA-иконки подготовлены

### Проблемы:
- **sslip.io домен** -- нет собственного домена, невозможно SEO, нет доверия у клиентов
- **Нет SSL на собственном домене** -- sslip.io предоставляет wildcard, но Яндекс/Google не индексируют такие домены
- **SEO минимальный** -- есть meta description и OG-теги, но нет structured data (JSON-LD), нет alt-текстов для изображений, нет hreflang
- **Нет страницы 404** -- при неверном URL пользователь видит JSON-ошибку FastAPI
- **Лендинг без социального доказательства** -- нет реальных кейсов, отзывов, логотипов клиентов
- **Метрики в trust-strip** -- "1 247 каналов проиндексировано" и пр. передаются через шаблон, но в реальности цифры могут быть нерелевантны
- **Нет видео/скриншотов продукта** -- hero-секция содержит только терминальную анимацию
- **Нет English-версии** -- только русский язык, CIS-only ограничение

### Рекомендации:
1. Купить домен neurocommenting.ru (или .io)
2. Настроить SSL через Let's Encrypt / Cloudflare
3. Добавить JSON-LD schema (Organization, SoftwareApplication, FAQPage)
4. Создать страницу 404
5. Добавить скриншоты/видео продукта на лендинг
6. Добавить блок с социальным доказательством (отзывы, лого клиентов)

## Минимальная готовность к soft launch (MVP маркетинга)

Для soft launch (первые 10-20 клиентов через ручные продажи) необходимо минимум:

1. ИП/ООО зарегистрировано
2. Домен куплен, SSL настроен
3. Почта работает
4. ЮKassa подключена (боевой режим)
5. Реквизиты заполнены в юридических страницах
6. Yandex.Metrica подключена
7. Telegram-канал запущен
8. Demo-видео готово

**Оценочный срок достижения soft-launch ready: 7-14 дней** (при условии регистрации ИП/ООО).
