## Summary

AiCommenting is a Russian neurocommenting service operated by IP Medvedeva L.R. (OGRN 323169000150200, INN 166023951607). It offers a ChatGPT-based commenting bot managed entirely through a Telegram bot interface. Operator: @anton_mp8.

## Key Features

1. **Write comments** using ChatGPT technology
2. **Connect to selected channel list** with one button press
3. **Auto-leave channels** where the bot got banned in comments
4. **Reply in DMs** to everyone who writes -- using randomized response templates (great for redirecting traffic)
5. **Notification chat** -- separate chat with all comment notifications
6. **Channel analytics** -- see analytics on all connected channels at any time
